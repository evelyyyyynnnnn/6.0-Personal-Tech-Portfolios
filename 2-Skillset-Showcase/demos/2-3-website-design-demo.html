Living Weather Card

A single-file weather widget whose entire palette is derived from the current condition — the theme hue, glow and particle layer all shift when the weather does.

How it works

  • One hue drives everything. A single --theme-hue variable recolours background, glow and text.
  • Condition → theme. Each weather state maps to a hue, saturation and particle layer.
  • Particles are CSS. Rain and stars are generated elements animated with keyframes, not canvas.
  • Long transitions. 1.4 s eases make the change feel atmospheric rather than abrupt.

Motorola Beeper Typewriter

A retro pager console wired to a sheet of typewriter paper: whatever you page through the device is printed, character by character, on the paper below.

HTMLCSS skeuomorphism Vanilla JSGoogle Fonts repo9-2-moto-beeper-typer.html

How it works

  • Two surfaces, one state. The LCD echoes input; the paper renders the committed message.
  • Typed output. A timed loop appends one character at a time with a blinking caret.
  • Texture in CSS only. The ruled paper is a repeating linear gradient; the case is layered box-shadows.
  • Special Elite from Google Fonts carries the whole typewriter illusion.

Accounting Ledger · 记账系统

A full-stack ledger that pulls entries from a Notion database, has an LLM assign a category to every transaction, and renders spending trends over a selectable date range.

ReactExpress Notion APIOpenAI GPT-4o-mini Vercel repo9-3-github-Account-Ledger/

How it works

  • Notion is the database. The Express backend pages through the API so datasets over 100 rows sync whole.
  • AI fills the gap. GPT-4o-mini reads each Description and assigns a category, cached so repeats cost nothing.
  • Deposit vs Payment. A row with Deposit set is income, a row with Payment set is expense — type is inferred, never typed in.
  • Range-driven views. The date picker auto-detects the earliest and latest entry and every chart follows it.
