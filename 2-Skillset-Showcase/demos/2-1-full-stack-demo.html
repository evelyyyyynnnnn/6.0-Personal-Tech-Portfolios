FS Full-Stack Blog

A personal blog that behaves like a product.

Docusaurus 3 with a heavily customised theme: MDX writing, i18n, PWA offline support, Algolia full-text search, switchable blog views, and a project / resource showcase — all statically generated and deployed on the edge.

What the site does

data/features.tsx · docusaurus.config.ts
✍️

MDX authoring

Posts and docs are plain Markdown with React components available inline — code sandboxes, browser windows, tooltips.

🔎

Algolia DocSearch

Full-text search across blog, docs and pages, indexed by a scheduled crawler defined in docsearch.json.

🖥️

PWA & offline

Installable app shell via @docusaurus/plugin-pwa with a custom service worker in src/sw.js.

🏞️

i18n

Locale-aware routing and translated UI strings under i18n/, with a locale dropdown in the navbar.

🗃️

Dual blog views

Readers switch between a reading list and a card grid; the choice is persisted in a useViewType hook.

📦

Project & resource pages

Custom pages driven by typed data files — projects, resources, friends and social links.

Blog view — interactive

filter by category, switch list ⇄ grid
