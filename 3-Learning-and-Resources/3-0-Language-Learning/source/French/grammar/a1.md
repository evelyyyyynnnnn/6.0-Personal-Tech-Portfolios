## {{Grammar points // 语法要点}}

```grammar
Les articles | Articles // 冠词
J’ai acheté un livre.
I bought a book.
zh: 我买了一本书。

Les pronoms personnels | Personal pronouns // 人称代词
Elle parle français.
She speaks French.
zh: 她说法语。

Les verbes réguliers | Regular verbs // 规则动词
Je danse tous les jours.
I dance every day.
zh: 我每天都跳舞。

Les verbes irréguliers | Irregular verbs // 不规则动词
Il est allé au cinéma.
He went to the cinema.
zh: 他去电影院了。

Les adjectifs qualificatifs | Descriptive adjectives // 品质形容词
J’ai une belle maison.
I have a beautiful house.
zh: 我有一栋漂亮的房子。

Les adverbes | Adverbs // 副词
Il court rapidement.
He runs quickly.
zh: 他跑得很快。

Les prépositions | Prepositions // 介词
Le livre est sur la table.
The book is on the table.
zh: 书在桌子上。

Les conjonctions | Conjunctions // 连词
Je suis fatigué, mais je vais étudier.
I am tired, but I will study.
zh: 我很累，但我还是要学习。

Les temps verbaux | Verb tenses // 动词时态
Hier, j’ai mangé au restaurant.
Yesterday, I ate at the restaurant.
zh: 昨天我在餐厅吃了饭。

La négation | Negation // 否定
Je n’aime pas le café.
I don’t like coffee.
zh: 我不喜欢咖啡。
```
