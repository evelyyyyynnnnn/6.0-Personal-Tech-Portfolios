```tr
Now let’s continue — ten patterns that take you past the present tense.
zh: 我们继续——十个句型，带你走出现在时。
```

```grammar
Le subjonctif | Subjunctive // 虚拟式
Il faut que tu viennes demain.
You need to come tomorrow.
zh: 你明天得来。

Le conditionnel | Conditional // 条件式
J’aimerais voyager autour du monde.
I would like to travel around the world.
zh: 我想环游世界。

Les pronoms relatifs | Relative pronouns // 关系代词
Voici la personne dont je t’ai parlé.
Here is the person I told you about.
zh: 这就是我跟你提过的那个人。

Les propositions subordonnées | Subordinate clauses // 从句
Je vais étudier jusqu’à ce que je comprenne.
I will study until I understand.
zh: 我会一直学，直到弄懂为止。

Les pronoms disjoints | Disjunctive pronouns // 重读人称代词
Pour moi, c’est difficile.
For me, it’s difficult.
zh: 对我来说，这很难。

Les participes passés | Past participles // 过去分词
J’ai vu le film hier soir.
I saw the movie last night.
zh: 我昨晚看了那部电影。

Les voix passive | Passive voice // 被动语态
Le livre a été écrit par Victor Hugo.
The book was written by Victor Hugo.
zh: 这本书是维克多·雨果写的。

Les temps du discours indirect | Tenses in indirect speech // 间接引语中的时态
Il a dit qu’il viendrait demain.
He said that he would come tomorrow.
zh: 他说他明天会来。

Les verbes pronominaux | Reflexive verbs // 代词式动词
Je me suis levé tôt ce matin.
I got up early this morning.
zh: 我今天早上起得很早。

Les phrases conditionnelles | Conditional sentences // 条件句
Si j’avais de l’argent, j’achèterais une maison.
If I had money, I would buy a house.
zh: 如果我有钱，我就会买一栋房子。
```
