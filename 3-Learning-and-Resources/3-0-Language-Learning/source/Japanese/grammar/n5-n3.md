```pair
こんにちは、ここでは次の基本的な表現から始めます:
👋Hello here we begin from the following basic expressions:
zh: 👋你好，我们从下面这些基础表达开始：
```

```grammar
主语 + は/が + 谓语 | 用于陈述句，表示主语是动作的执行者或主题。中文解释：主语是……。
私は学生です。 (Watashi wa gakusei desu.)
我是学生。

主语 + は/が + 名称/形容词 | 用于陈述句，表示主语具有某种属性或状态。中文解释：主语是……
彼は優秀です。 (Kare wa yūshū desu.)
他很优秀。

主语 + が/を + 目的/动作 | 用于陈述句，表示主语进行某种动作或针对某个对象进行操作。中文解释：主语做……
私が本を読みます。 (Watashi ga hon o yomimasu.)
我在读书。

主语 + に/へ + 动作/方向 | 用于陈述句，表示主语的动作或方向的目标地点。中文解释：去……
私は学校に行きます。 (Watashi wa gakkō ni ikimasu.)
我去学校。

时间 + に + 动作 | 用于陈述句，表示某个动作发生的时间点。中文解释：在……
朝に起きます。 (Asa ni okimasu.)
早上起床。

动词/形容词/名词 + です | 用于陈述句，表示肯定句的结尾，相当于中文的“是”。中文解释：是……
犬です。 (Inu desu.)
是一只狗。

动词/形容词/名词 + じゃないです | 用于否定句的结尾，表示否定或否认。中文解释：不是……
元気じゃないです。 (Genki ja nai desu.)
不是很好。

～てください | 用于请求或命令，表示请求对方做某个动作。中文解释：请……
座ってください。 (Suwatte kudasai.)
请坐。

～たい | 用于表达愿望或欲望，表示希望做某个动作。中文解释：想要……
旅行したいです。 (Ryokō shitai desu.)
想要旅行
```
